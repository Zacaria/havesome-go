Prompt transmis :

> Create one new landscape editorial illustration for a Go programming language reference. Show only a clean abstract software process: a code editor containing abstract horizontal lines, linked to three concurrent processes that converge on one output. Warm cream paper, navy ink, restrained cyan, and refined screenprint texture. No readable text, logos, mascots, or watermark. Exclude all boards, board games, stones, gaming pieces, and landscapes.
